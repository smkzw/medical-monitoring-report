# Query 写作规范

## 结构
`[访视（日期）] [检查项/记录] [原值 单位]（参考范围 …；<分级标准> x 级），[研究者现有记录]。` + `[请求]`
- 事实部分：只写源数据可见内容（原值、单位、范围、判定、关联字段、基线值）；不写推断结论，不写“漏报”。
- 请求部分：可操作、可关闭：“请评估是否需记录为 AE；如已记录，请在关联字段中关联对应 AE 编号。”
- 一条 query 对应一个 EDC 单元格/记录；同一单元格多个信号合并（`mergeSameCell`），第二个事实以「另：」追加。
- 范围写法：双侧 `3.5–9.5`，单侧 `≤40` / `≥60`（`K.rng`/`{rng}` 自动处理）；数值与单位之间留空格；`10^9/L` 自动写为 `×10^9/L`。

## 不发 query 的情形
- 已关联 AE 且等级一致；NCS 且 <2 级；技术性超范围且判正常（仅提示）；中心偏离（中心沟通）；基线回退（仅提示）。
- 规则信号 pr < `queryMinPr`，或规则 `query:false`。

## 与 CRO 已发质疑查重
同受试者 + 表单匹配（sheet / `labGroups` / findings group / `formNames`）后，按中文二元组重叠度 + 共同数字 + `synonyms` 判定：
- `重叠 ≥ dedupMinOverlap`，或含相同数字且 `≥ dedupMinOverlapNum` → 「同主题已查重」，展示 CRO 原文；
- CRO 原文含 `conflictRe`（无需/删除…）→ 标记「与 CRO 意见冲突」，由 MM 决定。

## 工作簿
`export_queries.py` 复制证据行最多的 listing，在每个相关 sheet 的**首列**插入「申办方MM query」，在对应源行写入 query 文本（多条换行），可直接对照 EDC 粘贴。

## 示例
- CSX：`W4（2026-03-02）丙氨酸氨基转移酶 128 U/L（参考范围 ≤40；CTCAE v5.0 2 级），研究者判定「异常有临床意义」，但未关联不良事件或病史。请评估是否需记录为 AE；如已记录，请在关联字段中关联对应 AE 编号。`
- CSX_AE：`…研究者判定「异常有临床意义」；同期已记录 AE「转氨酶升高」（2026-03-01），但该检查记录未关联。请确认是否为同一事件并完成关联。`
- NCS2：`W8（…）中性粒细胞计数 0.9 ×10^9/L，按 CTCAE v5.0 数值达 3 级（中性粒细胞计数降低），研究者判定「异常无临床意义」。请说明判定依据或更正临床意义评价。`
