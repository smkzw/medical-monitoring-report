# 设计体系与用户偏好（康哲 · kangzhe-design v6.1.3）

## 色彩
| 用途 | 色值 |
|---|---|
| 品牌橙 / 品牌黄 | `#FF9900` / `#FFCC00` |
| 正文标题 ink | `#0F1115` |
| 正文 body | `#404040` |
| 次要 muted | `#64676B` |
| 高风险（深红） | `#8B0000` |
| 信息蓝 / 正向绿 / 棕 | `#407AAA` / `#587B3B` / `#A85F34` |
风险色阶：深红（CSX/阻断）> 橙（MH/需确认）> 黄（NCS2/提示）> 灰（无需处理）。

## 规范（来自用户反馈，必须遵守）
- **不要整宽的边缘色条**（卡片左/上满宽彩条）；强调用小标签（pill）、数字颜色或细描边。
- KPI：中心数值突出，总体数值淡显在旁。
- 图表：ECharts v6；数值跨度大时用**轴断裂**；参考线标注来源（如“AESI 500”）；漏斗图 ±2SE 虚线 / ±3SE 点线。
- 时间线：风险事件**单独成行**，不与给药/AE 条带重叠。
- 盲态：不出现分组、不出现可揭示分组的有效性对比（在页面明确标注“盲态”）。
- USV/ET 不进入汇总；个例中保留并标注。
- 中文排版：数值与单位间留空格；范围用 “–”；单侧范围用 ≤/≥。
- 字体：系统中文无衬线（PingFang SC / Microsoft YaHei / Noto Sans SC），数字等宽（tabular-nums）。
- 品牌：页眉 `cfg.brand.logo`（默认 assets/logo_bot.svg）、页脚 `cfg.footer`。

样式实现集中在 `templates/site/assets/kz.css`；新增组件沿用现有 class（`card`、`sec-t`、`pill`、`tabs`、`kpi`、`muted`、`small`）。
